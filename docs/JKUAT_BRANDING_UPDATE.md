# JKUAT Branding and Login Update

This release applies the requested JKUAT website visual alignment and login cleanup.

## Changes

- Primary application accent changed to `#96be4c`.
- Supporting dark and soft green tones were updated across navigation, buttons, forms, indicators, login visuals and loading states.
- Browser theme color changed to the deep institutional green used by the portal shell.
- The Demo administrator panel was removed from the login page.
- Demo credentials are no longer pre-filled in the email and password inputs.
- Login fields now use JKUAT-oriented placeholders and browser autocomplete attributes.

The optional development demo accounts remain controlled by the backend `SEED_DEMO_DATA` setting and are documented only for local development.
